# 私人营养主厨（Private Nutrition Chef）

你的**私人营养主厨**。它记录你的口味画像与厨房库存，按 **100 分制评分卡**推荐「一餐组合」（而不是单道菜），从 **GitHub 开源菜谱仓库**获取菜谱，输出可执行的做饭步骤与**并行时间轴**。

## 核心能力

- 🎭 **三份提示词协作**：主控（SKILL.md）+ 主厨（prompts/chef.md）+ 营养师（prompts/nutritionist.md），职责分离、打分互不越权
- 🍜 **分层菜谱数据源**：GitHub 开源仓库（raw/API 直读）+ 中文菜谱站点（下厨房、豆果美食、美食杰、香哈菜谱、好豆菜谱、日日煮、美食天下）+ TheMealDB，全部联网即取，无爬虫、无本地缓存
- 🧮 **100 分制评分卡**：营养师 35 + 厨师 30 + 执行 25 + 个人 10，共 19 项指标，对一餐组合整体打分并附补分建议
- ⏱ **做饭时间轴**：多道菜并行排程（Gantt 风格，默认 5 分钟粒度，支持"现在开始"正排与"几点开饭"倒排）
- 🧑‍🤝‍🧑 **口味画像**：首次 onboarding 9 问，此后每次对话增量演进，永不重置
- 📖 **做饭历史**：全量永久记录（日期/菜名/评分/备注）；主动推荐近 14 天不重复，用户点名可随时重做
- ⚠️ **过敏原双保险**：用户自身过敏原硬过滤 + 常见过敏原（花生/海鲜/蛋/奶/麸质/大豆/芝麻）无论用户是否过敏都突出标注
- 🧂 **调料替代方案**：每种调料尽量附 1-2 个替代方案，缺料不慌
- 🗄 **厨房库存**：工具 / 常备 / 冰箱食材，临期优先消耗；未录入库存时默认"什么菜都能做"
- 🚫 **当天食材不重复**：一餐内主蛋白与同种蔬菜不重复，重复即扣分

## 目录结构

```
private-nutrition-chef/
├── SKILL.md                  # 主控：触发条件、8 步工作流、数据读写、输出约定
├── prompts/
│   ├── chef.md               # 主厨：GitHub 取菜谱、步骤格式、B+C 评分、时间轴排程
│   └── nutritionist.md       # 营养师：红线审核、过敏原标注、A 评分、饮食模式
├── assets/
│   ├── chef-profile.md       # 口味画像模板（首次 onboarding 后填充）
│   ├── recipe-history.md     # 做饭历史模板（全量记录 + 点名重做）
│   └── pantry.json           # 厨房资产模板（tools / pantry / fridge）
└── README.md
```

## 工作流

1. 读画像（不存在 → 完整 onboarding 9 问并写入画像）
2. 必问问答 4 项（几人吃 / 几点开饭或时长 / 口味忌口变化 / 库存变化；人数与时间必须明确回答，口味库存可答"照旧"）
3. 读历史（14 天排除窗口）与库存（无库存 = 什么都能做）
4. 营养师红线审核候选（过敏原 / 工具 / 时间 / 明确不吃的）
5. 主厨从 GitHub 开源仓库取菜谱、排时间轴
6. 主厨打 B+C、营养师打 A、主控打 D，汇总总分
7. 输出 Top 3 组合：评分卡 + 食材清单（含过敏原标记与调料替代）+ 补分建议 + 时间轴
8. 饭后问反馈 → 更新画像 + 全量写入做饭历史

## 评分卡（100 分制 · 19 项）

| 模块 | 分值 | 指标 |
|---|---|---|
| A 营养师视角 | 35 | 优质蛋白 8 · 蔬菜覆盖 8 · 主食合理 6 · 油盐克制 5 · 食材多样性 4 · 模式匹配 4 |
| B 厨师视角 | 30 | 口感层次 8 · 味型平衡 7 · 技法多样 6 · 颜色呈现 5 · 温度结构 4 |
| C 执行视角 | 25 | 食材覆盖率 8 · 时间匹配 6 · 工具匹配 5 · 临期消耗 3 · 当天去重 3 |
| D 个人匹配 | 10 | 口味画像 4 · 历史新鲜度 4 · 场景匹配 2 |

红线一票否决：用户过敏原出现 / 缺关键工具 / 时间完全不够 / 用户明确不吃的食材。

## 菜谱数据源（分层，全部联网即取）

| 层 | 源 | 获取方式 |
|---|---|---|
| 1 开源仓库 | HowToCook（391 .md）、CookLikeHOC（354 .md）、YunYouJun/cook、based.cooking、The-Cookbook、中国名菜谱 | GitHub raw 直读 + contents API |
| 2 中文站点 | 下厨房、豆果美食、美食杰、香哈菜谱、好豆菜谱、日日煮、美食天下 | 搜索定位 → 打开页面提取正文 |
| 3 国际源 | TheMealDB | 网站菜谱页直读（无需 API key） |

## 安装与使用

1. 将整个 `private-nutrition-chef` 文件夹放入技能的 skills 目录（AutoClaw：`~/.openclaw-autoclaw/skills/`；OpenClaw：`~/.openclaw/skills/` 或配置的 skills 目录）
2. 自然触发：**"今晚吃什么"、"推荐几个菜"、"帮我做饭"、"这道菜怎么做"**
3. 首次使用会进入 onboarding 画像采集，此后自动加载

## 数据文件

- `assets/chef-profile.md`：口味画像，由技能自动生成与演进，用户可随时修改
- `assets/recipe-history.md`：做饭历史，全量记录
- `assets/pantry.json`：厨房资产，对话中自然语言增量更新（"鸡蛋没了"、"买了牛腩 500g"）
