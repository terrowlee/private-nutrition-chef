# private-nutrition-chef
私人营养主厨：记录口味画像与厨房库存，以 100 分制评分卡（营养师+厨师）推荐一餐组合，从 GitHub 开源仓库、下厨房等站点联网取菜谱，输出并行做饭时间轴。Private Nutrition Chef: a skill that learns your tastes, scores meal combos on a 100-point rubric, fetches recipes from GitHub &amp; Chinese recipe sites, and builds parallel cooking timelines.
